# 01 - ROS 2 基础

## 核心概念

```
┌─────────────┐   发布(Publish)    ┌──────────────┐
│   talker    │ ─────────────────► │   /chatter   │  ← 话题(Topic)
│  (节点 Node) │                    └──────┬───────┘
└─────────────┘                            │ 订阅(Subscribe)
                                    ┌──────▼───────┐
                                    │   listener   │
                                    └──────────────┘
```

- **节点 (Node)**：独立运行的进程
- **话题 (Topic)**：节点间消息通道
- **消息 (Message)**：话题中的数据（如 std_msgs/msg/String）
- **DDS 中间件**：节点自动互相发现，ROS 2 不需要 roscore

## 常用命令

```bash
source /opt/ros/humble/setup.bash   # 每个终端都要先加载环境
ros2 node list                      # 查看运行中的节点
ros2 topic list                     # 查看话题
ros2 topic echo /chatter            # 实时查看话题内容
ros2 topic hz /chatter              # 查看发布频率
ros2 run <包名> <节点名>             # 运行节点
```

## 第一个实验：talker/listener

```bash
# 终端 1
ros2 run demo_nodes_cpp talker
# 终端 2
ros2 run demo_nodes_cpp listener
# 终端 3（观察）
ros2 topic echo /chatter
```

## 关键认知

- RViz ≠ ROS：RViz 只是可视化窗口，关掉它后台节点还在跑
- 同一个 ROS 域（ROS_DOMAIN_ID）里的节点会自动通信
- **同名节点/同名话题共存会互相污染**（见踩坑记录）
