# 03 - 珞石 SR5 部署记录

机器人型号：**SR5-5/0.9c**（珞石 xMate SR 系列，6 轴）

## 1. 下载 rokae_ros2

官方仓库：https://github.com/RokaeRobot/rokae_ros2（ROS2 Humble + ros2_control + MoveIt 2）

> 国内 git clone github.com 经常卡死，改用 codeload 源码包：
> ```bash
> cd /media/administrator/D/Projects/Rokae
> curl -sL -o rokae_ros2.tar.gz \
>   "https://gh-proxy.com/https://codeload.github.com/RokaeRobot/rokae_ros2/tar.gz/refs/heads/main"
> tar xzf rokae_ros2.tar.gz && mv rokae_ros2-main rokae_ros2
> ```
> （gh-proxy 不稳定时去掉前缀直连 codeload 试试）

## 2. 下载 xCore SDK 预编译库

版本要求见 `rokae_hardware/sdk/VERSION`（当前 0.7.1）：

```bash
curl -sL -o xCoreSDK-0.7.1-linux-x86_64.tar.gz \
  "https://gh-proxy.com/https://github.com/RokaeRobot/xCoreSDK-CPP/releases/download/v0.7.1/xCoreSDK-0.7.1-linux-x86_64.tar.gz"
# 解压后把 lib/Linux/x86_64/ 下所有库复制到 rokae_hardware/sdk/lib/
# 并创建符号链接: ln -sf libxCoreSDK.so.0.7.1 libxCoreSDK.so
```

## 3. 依赖与编译

```bash
sudo apt install -y python3-rosdep python3-colcon-common-extensions
sudo rosdep init && rosdep update
cd /media/administrator/D/Projects/Rokae
sudo -E rosdep install --from-paths rokae_ros2 --ignore-src -r -y   # 会装 Gazebo 全家桶(~1GB)
colcon build --symlink-install                                       # 19 个包全部通过
```

## 4. 启动

**仿真模式**（验证软件链，不连真机）：
```bash
source /opt/ros/humble/setup.bash
source /media/administrator/D/Projects/Rokae/install/setup.bash
ros2 launch rokae_hardware rokae_moveit_launch.py robot_type:=SR5 use_fake_hardware:=true
```

**真机模式**：
```bash
ros2 launch rokae_hardware rokae_moveit_launch.py robot_type:=SR5 \
  use_fake_hardware:=false robot_ip:=<控制器IP> local_ip:=<本机IP>
```
真机前提：电脑与控制器同网段（默认控制器 192.168.21.10），控制器固件 ≥ v3.2.1。

**运动示例 demo**（需先启动上面的整机链路）：
```bash
ros2 launch rokae_example joint_s_line.launch.py robot_type:=SR5
# 其他: cartesian_s_line / follow_joint_position / follow_cart_position / servoj_demo
```
