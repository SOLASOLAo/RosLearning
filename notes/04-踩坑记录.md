# 04 - 踩坑记录

## 坑 1：ros2_control_node 崩溃（std::bad_alloc / Resource temporarily unavailable）

**现象**：启动 MoveIt demo 时控制器加载失败，ros2_control_node 崩溃。

**原因**：controller_manager 需要实时调度（FIFO）+ 锁定内存（mlockall），
普通用户默认 memlock 限制不够。

**解决**：`/etc/security/limits.conf` 追加（然后重新登录/重启）：
```
<用户名> - memlock unlimited
<用户名> - rtprio 99
<用户名> - nice -20
```
生效前临时方案：`sudo bash -c 'ulimit -l unlimited; ...'` 启动。

## 坑 2：多个演示同时跑导致 ROS 域污染

**现象**：启动 SR5 时 move_group 疯狂报 `Joint 'panda_jointX' not found in model 'xMate_robot'`，
joint_state_broadcaster 加载 FATAL。

**原因**：之前 Panda 演示的进程没关干净：
- 两个 `/controller_manager` 同名节点 → spawner 请求发到旧节点
- Panda 的 joint_state_broadcaster 往 /joint_states 灌 panda 关节
- TF 树冲突

**教训**：切换演示前先 `pkill` 清干净所有 ROS 节点，确认 `ros2 node list` 为空。

## 坑 3：编译时电脑卡死

**现象**：colcon 编译 moveit2_tutorials 时整机卡死，只能重启。

**原因**：RViz(3D渲染) + ros2_control(1000Hz RT线程) + 满载编译(10核) 同时跑，
7.7GB 内存耗尽 → swap 风暴。

**对策**：
- 编译前停掉 RViz 和机器人节点
- `MAKEFLAGS="-j4" colcon build --executor sequential` 限制并行
- 编译时不开 3D 窗口

## 坑 4：github.com git 协议不通

**现象**：`git clone https://github.com/...` 卡住（0% 进度）。

**解决**：改用 codeload 源码包 + gh-proxy 代理：
```bash
curl -sL -o repo.tar.gz "https://gh-proxy.com/https://codeload.github.com/<org>/<repo>/tar.gz/refs/heads/<branch>"
```
Release 资产同理：`https://gh-proxy.com/https://github.com/<org>/<repo>/releases/download/<tag>/<file>`

## 坑 5：RViz "Save Config As" 特别卡

**原因**：RViz 渲染循环占满单核（MoveIt 场景持续更新、不限帧率），
文件对话框和渲染共用 Qt 主线程；GTK 对话框打开时还要枚举 gvfs 网络位置。

**对策**：用 Ctrl+S（Save Config）不弹对话框；Save As 时直接输入完整路径。

## 坑 6：pkill 误杀自己的 shell

`pkill -f "某模式"` 时，如果模式字符串出现在自己的命令行里，会把自己杀掉（exit 143）。
用括号技巧：`pkill -f "rv[i]z2"`（正则匹配 rviz2，但不匹配字面量 rv[i]z2）。

## 坑 7：warehouse-ros-mongo 安装失败

Humble 的镜像源已移除该包（改用 sqlite 实现），rosdep 报错可忽略，不影响使用。
